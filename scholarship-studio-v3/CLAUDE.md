# Scholarship Studio V3

Use the project's installed design skills for frontend work in this directory. Start with the smallest relevant set:

- `design-engineering` + `ui-ux-pro-max` for hierarchy/layout.
- `emil-design-eng` for interaction polish.
- `find-animation-opportunities` before adding motion; use `animate` / `design-motion-principles` only after motion passes the frequency/purpose gate.
- `mobile-native` + `material-3` for touch/accessibility/responsive checks.
- `karpathy-guidelines` for implementation discipline.
- `webapp-testing` for final verification.

Do not animate core navigation. Do not add motion just to make the page feel busy. Preserve all scholarship data and functional behavior. Keep the coastal teal identity and use the warm yellow accent sparingly. Run the existing Scholarship Studio V3 visual-QA workflow after frontend changes.
